## Why Japanese online banking confuses foreigners

| Friction | What it feels like |
| --- | --- |
| **Japanese-first UI** | English partial or absent |
| **Multi-step login** | Card reader, app code, SMS |
| **No instant Zelle vibe** | Furikomi has cut-off times |
| **Branch culture** | Some tasks still need counter |
| **Cash card naming** | Not the same as debit abroad |
| **Strict name matching** | Katakana must match exactly |

The system prioritizes **fraud prevention** over speed.

## Furikomi bank transfers

Domestic transfers use **branch code + account number + account name**.

| Field | Tip |
| --- | --- |
| **Bank name** | Search from list, do not guess code |
| **Branch (支店)** | 3 digits, critical |
| **Account type** | Ordinary (普通) vs current (当座) |
| **Account number** | 7 digits usually |
| **Recipient name** | Katakana exact, or kanji per bank rule |

**Example:** Pay rent ¥85,000 to landlord.

| Step | Action |
| --- | --- |
| 1 | Open app, choose furikomi |
| 2 | Select saved recipient or enter new |
| 3 | Enter amount ¥85,000 |
| 4 | Confirm fee (¥0-¥330 typical) |
| 5 | Authenticate with OTP or token |
| 6 | Save screenshot confirmation number |

**Timing:** Same-bank often instant. Other banks may settle same business day if before cut-off (often 3 p.m.).

## Cash cards vs debit cards explained

| | **Cash card** | **Debit card** |
| --- | --- | --- |
| **Main use** | ATM cash, some in-store | Visa/Master pay at shops |
| **Linked to** | Bank account | Same account often |
| **Overseas ATM** | Sometimes, with fees | Debit uses shop network |
| **Common abroad** | Japan-centric | Familiar to foreigners |

Many residents use **cash card + mobile pay** before debit arrives.

Credit cards are separate products: [credit cards in Japan](/residents/japan-credit-cards).

| **Security card grid** | Older paper grid codes |

| Level | What you get |
| --- | --- |
| **Full English app** | Rare |
| **English PDF guides** | Some online banks |

## Security and fraud prevention systems

| System | Purpose |
| --- | --- |
| **Transfer limits** | Daily cap until you raise |
| **New payee delay** | Cooling period |
| **Phishing warnings** | Banks never ask password by email |
| **Device binding** | New phone needs re-registration |

Never share **OTP codes** with anyone claiming to be bank support.

## Common mistakes foreign residents make

- Wrong **branch code** on furikomi (money bounces back after days)
- Name in **romaji** when bank wants katakana
- Deleting bank app without saving **customer number**
- Ignoring **transfer fee** on small test sends
- Using **tourist SIM** number on account then losing access
- Assuming **Wise/Revolut** replaces Japanese bank for utilities
- Large transfer Friday 6 p.m. expecting instant clearance

## FAQ

### Can I use online banking without Japanese?

Some banks offer partial English. Translate UI for daily tasks.

### Is furikomi the same as wire transfer?

Domestic furikomi is local transfer. International is separate product.

### Why was my transfer rejected?

Wrong branch, name mismatch, or insufficient funds. Check error code in history.

### Do I need a hanko for the app?

Usually no. Branch paper forms may still want seal.

### Can I use banking app overseas?

Login sometimes blocked abroad without travel notice. Check bank policy.

### What is a cash card fee?

Annual fee ¥0-¥1,100 depending on bank. ATM fees outside free windows.

### How do I raise transfer limits?

Branch request or in-app verification with income proof.

### Can PayPay replace my bank?

No for salary, rent, and utilities. PayPay links to bank.

### Are banking apps safe?

Major banks use strong auth. Avoid fake apps; download from official store only.

### What if I lose my cash card?

Call bank hotline immediately to suspend. Listed on bank website.

## Why apartment viewings in Japan feel misleading at first

| Factor | Why it tricks you |
| --- | --- |
| **Wide-angle photos** | Rooms look larger |
| **Staging** | Lights on, minimal furniture |
| **Short visit** | Pressure to decide |
| **Agent language barrier** | Miss fine print clues |
| **Unique market** | Key money, guarantor, deposits |

You are not only choosing a room. You are choosing **sound, sun, commute, and building maintenance** for one to two years.

**Foreign residents misunderstand this:** Judging by rent and train minutes alone. **Physical unit quality** varies wildly at the same price.

**Viewing scenario:** Two units same rent. Unit A: south light, thick door, quiet street. Unit B: north, highway hum, thin walls. Photos looked identical online. Twenty minutes of checking saves two years of fatigue.

## The difference between listing photos and reality

| Photo trick | On-site check |
| --- | --- |
| **Ultra-wide lens** | Bring tape measure or compare to tatami count |
| **Furniture not included** | Empty room size |
| **Seasonal light** | Visit similar time of day you will live |
| **Cropped view** | Look out window fully |
| **Renovation "before" hidden** | Smell, stains, uneven floors |

| Ask agent | Why |
| --- | --- |
| **When were photos taken?** | Season, renovation |
| **What is included?** | AC, washer space, curtains |
| **Any planned construction nearby?** | Noise future |

## Building age and construction realities

| Era (rough) | Typical traits |
| --- | --- |
| **Pre-1980** | Thinner insulation, older pipes |
| **1980-2000** | Common steel frame, variable sound |
| **2000+** | Better insulation sometimes, higher rent |
| **RC (reinforced concrete)** | Often quieter between units |
| **Wooden / light steel** | Sound travels more |

| Building comparison example | Unit A (1985 wood) | Unit B (2015 RC) |
| --- | --- | --- |
| Train noise | Audible | Muffled |
| Summer heat | Hotter | Easier with AC |
| Rent | Lower | Higher |
| Floor squeak | Possible | Less |

| Check | How |
| --- | --- |
| **Lobby condition** | Maintenance culture |
| **Elevator age** | Breakdown risk |
| **Hall smell** | Mold, smoke |
| **Earthquake info** | Building inspection sticker (新耐震, etc.) |

## Sunlight and room orientation

| Direction (Japan) | Light pattern |
| --- | --- |
| **South (南)** | Bright, popular, warmer |
| **East (東)** | Morning sun |
| **West (西)** | Afternoon hot summer |
| **North (北)** | Dim, cooler |

| Viewing tip | Action |
| --- | --- |
| Visit **daytime** | See real light |
| Open curtains | Check window size |
| Stand in each room | Note dark corners |
| Winter vs summer | Ask current tenant feel if possible |

**Foreign residents misunderstand this:** "High floor = bright." A **north-facing high floor** can feel dark all day.

## FAQ

### How long are viewings?

Often 15-30 minutes. Ask extra 10 min if serious.

### Can I record video?

Ask agent first. Personal photos usually OK.

### Should I view at night?

Helpful for noise and safety once shortlisted.

### What if agent rushes?

Politely insist on checklist. Walk away if blocked.

### Do foreigners face viewing bias?

Sometimes. Agency specializing in foreigners helps. See renting guide.

### Is first floor bad?

More noise, security tradeoff. Cheaper, easier move.

### How important is south-facing?

Very for light lovers. Less critical if out all day.

### Can I negotiate rent after viewing?

Sometimes on slow listings. Popular units rarely.

### What documents after viewing?

Application, ID, income proof, guarantor. See renting guide.

### Should I bring a friend?

Yes for second opinion and measuring.

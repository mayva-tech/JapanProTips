## Burnable vs non-burnable trash explained

| Category (common labels) | Examples | Not examples |
| --- | --- | --- |
| **Burnable (燃やすごみ / 可燃)** | Food scraps, tissues, dirty paper | Metal, glass |
| **Non-burnable (燃やさない / 不燃)** | Ceramics, glassware, metal small items | Food waste |
| **Raw waste (生ごみ)** | Some cities separate food | Check chart |

| Daily kitchen flow | Bin at home |
| --- | --- |
| Cook | Scraps to burnable bag |
| Eat | Bones if chart allows burnable |
| Clean | Tissues burnable if not plastic-coated |

Rinse **bottles and jars** before non-burnable if required locally.

## Plastic recycling realities

**Plastic (プラ)** is its own stream in many cities, not burnable.

| Item | Usually |
| --- | --- |
| **Food trays, wrappers** | Plastic stream |
| **Shopping bags** | Plastic if clean and dry |
| **Styrofoam trays** | Plastic or dedicated |
| **Dirty greasy plastic** | Often burnable if chart says |

| Tip | Action |
| --- | --- |
| Rinse and dry | Workers accept |
| Flatten trays | Saves space |
| Check mark プラ | On packaging |

## Oversized garbage (sodai gomi)

**Sodai gomi (粗大ごみ)** is official bulky waste, not secret midnight dump.

| Item | Path |
| --- | --- |
| Sofa, mattress | Book pickup, pay sticker |
| Bicycle | Sodai gomi or recycle shop |
| AC, fridge | Retailer take-back or sodai gomi |
| Microwave | Often sodai gomi fee |

| Step | Action |
| --- | --- |
| 1 | Call or web book city pickup |
| 2 | Buy **shori ken** fee sticker |
| 3 | Attach sticker, place at spot by date |
| 4 | Item collected morning |

| Illustrative fee (Tokyo ward) | Item |
| --- | --- |
| ¥2,000-¥5,000 | Chair |
| ¥3,000-¥8,000 | Mattress |
| ¥5,000+ | Large shelf |

| Path | When |
| --- | --- |
| **Retailer when buying new** | Take old unit |

## Common mistakes foreign residents make

- Using **wrong color bag**
- Putting **recyclables in burnable** to save time
- **Oversized in garbage room** blocking others
- Dumping on **street before pickup day**
- Missing **cap removal** on PET
- **Wet cardboard** in paper stream
- Ignoring **collection time** (morning only)

## FAQ

### Is Japan trash sorting really strict?

Local and social. Learn your chart, mistakes become rare.

### What if I use wrong bag once?

May not be collected. Re-sort and retry next date.

### Can I throw furniture in garbage room?

No. Use sodai gomi booking.

### Where to buy garbage bags?

Supermarket, konbini, home center in your city.

### Are pizza boxes burnable?

Often yes if oily, some cities say plastic. Check chart.

### What about drinking bottles from konbini?

Consume there or carry home. Do not leave on street.

### How to dispose microwave?

Sodai gomi or retailer. Not burnable bag.

### Can I burn plastic?

Usually no. Plastic stream.

### What if I miss collection day?

Store sealed until next day. Avoid smell.

## Why cooking in Japan feels different at first

| Abroad habit | Japan reality |
| --- | --- |
| **Large fridge** | Compact, often no freezer drawer |
| **Oven dinners** | Few apartments have full ovens |
| **Bulk Costco runs** | Smaller baskets, frequent trips |
| **Mild seasoning** | Soy, dashi, miso base many dishes |
| **Hard cheese and bread** | Smaller aisles, higher import price |
| **Trash any night** | Burnable vs raw rules |

You are adapting to **space, flavor, and disposal**, not only new recipes.

## Small kitchen realities in Japanese apartments

| Feature | Common in 1K / 1DK |

| **2-burner gas or IH** | Yes |
| **Full oven** | Rare |
| **Range hood** | Weak in older units |
| **Counter space** | 60-90 cm total |
| **Sink** | Single bowl, dish rack on top |

| Layout type | Cooking impact |
| --- | --- |
| **Kitchenette in room** | Smells reach bed |

| **New tower condo** | IH, sometimes dishwasher |

## Japanese staples residents learn to use

### Soy sauce (醤油)

| Type | Use |
| --- | --- |
| **Koikuchi (dark)** | Default all-purpose |
| **Usukuchi (light)** | Subtle color, Kansai style |
| **Tamari** | Gluten-free option, richer |

One bottle lasts months. Refrigerate after opening if label says so.

### Mirin and cooking sake

| Item | Role |
| --- | --- |
| **Hon mirin** | Sweetness, glaze |
| **Cooking sake (ryorishu)** | Depth, removes smell |
| **Substitute** | Sake plus sugar in pinch |

### Dashi

| Form | Beginner note |
| --- | --- |
| **Powder or granules** | Fast miso soup |
| **Liquid dashi** | Convenient |
| **Kombu and katsuobushi** | Traditional, extra step |

Dashi is umami base for soup, tamagoyaki, and simmered dishes.

### Rice

| Type | Note |
| --- | --- |
| **Japanese short grain** | Sticky, daily standard |
| **5 kg bag** | Standard household size |
| **Rinse until clear** | Texture changes if skipped |

### Frozen foods

| Frozen item | Why residents buy |
| --- | --- |
| **Mixed vegetables** | Stir-fry backup |
| **Gyoza** | Quick dinner |
| **Edamame** | Side dish |
| **Shumai / croquettes** | Late work nights |
| **Rice balls (onigiri)** | Emergency lunch |

## Cooking smells and apartment etiquette

Thin walls mean **smell travels**.

| Smell level | Dish examples |
| --- | --- |
| Low | Rice, miso soup, boiled veg |
| Medium | Stir-fry, curry |
| High | Fried fish, karaage oil, bacon |

| Etiquette | Action |
| --- | --- |
| Use range hood | Always on |
| Close kitchen door if exists | Helps |
| Fry fish rarely | Or use outdoor vent areas |
| Open window after | Cross breeze |
| Avoid 深夜 strong cooking | Late night noise plus smell |

Neighbor complaints can reach management. Fish on weekday night in a studio is risky.

## FAQ

### Can I cook Western food in a Japanese apartment?

Yes. Toaster oven and stovetop handle most dishes. Skip recipes needing full-size oven unless you have one.

### Do I need a rice cooker?

Not required, but most residents buy one within the first month. Worth it for texture and timing.

### Is gas or IH better for cooking?

Gas gives flame control. IH is safer and common in new buildings. Match your pans.

### Where do foreigners buy cheese and pasta?

KALDI, Costco, import sections, Amazon Japan.

### How do I reduce cooking smells?

Hood on, lid on, avoid deep frying fish indoors, ventilate after.

### Is frozen food unhealthy in Japan?

Quality is high. Balance with fresh vegetables.

### Can I meal prep for five days?

Small fridges limit this. Freeze portions or prep components only.

### What if my kitchen has no hood?

Open window, use less oil, prefer boil and steam methods.

### Are 100 yen shop knives enough?

Start yes, upgrade one chef knife when you cook often.

### How much does home cooking save vs konbini?

Often **¥30,000-¥60,000/month** for singles who switch most dinners.

### Do I need Japanese recipes?

Start bilingual blogs and YouTube. Supermarket labels teach vocabulary.

### What about water for rice?

Filtered or tap per local taste. Soak time matters more than brand.
